# Quick chat

Quick chat starts a thread without a project from anywhere on your computer. Press its shortcut, type
a message, and press Enter. It is available in the desktop app on macOS and Windows.

## Turning it on

Open **Settings** > **General** > **Quick chat** and turn it on. The default shortcut is
Option+Space on macOS and Alt+Space on Windows. Select the shortcut to record a different one. T3
Code refuses shortcuts that it already uses, that SnapShots use, or that another app has taken.

## Starting a thread

The window opens at the bottom of the screen you are working on. Threads start on this machine.
When other connected machines can host threads without a project, select the machine name to run
the thread on one of them instead. The next time you open quick chat, it starts on this machine
again.

The thread uses that machine's **Default model** from **Settings** > **General** > **New threads**.
Without one, it uses the default model of the first ready provider. The model is shown next to the
machine name.

After you send, the window shrinks to show the thread's title and status. Select **Open in T3 Code**
to continue in the app, or close the window and let the thread keep running. Escape or the shortcut
also closes it.
